# UPI-Fraud-Detection-Using-ML
**UPI Fraud Detection Using Machine Learning:** Developed a machine learning-based system to identify fraudulent UPI transactions by analyzing transaction patterns and user behavior. Applied data preprocessing, feature engineering, and classification algorithms to improve fraud detection accuracy, reduce false positives, and enhance digital payment security.
**UPI Fraud Detection Using Machine Learning**

This project uses Machine Learning techniques to detect fraudulent UPI (Unified Payments Interface) transactions. It analyzes transaction data such as amount, transaction time, location, and user behavior patterns to identify suspicious activities. Various ML algorithms are trained and evaluated to classify transactions as legitimate or fraudulent. The system aims to improve digital payment security by providing accurate and real-time fraud detection, helping financial institutions and users prevent financial losses.

**Key Features:**

* Data preprocessing and feature engineering
* Fraud detection using ML algorithms
* Model training, testing, and evaluation
* Performance metrics visualization
* Real-time transaction risk prediction
* Secure and scalable fraud detection framework

**Technologies Used:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

**Objective:**
To build an intelligent fraud detection system that enhances the security of UPI transactions by identifying fraudulent activities with high accuracy and minimal false alarms.
